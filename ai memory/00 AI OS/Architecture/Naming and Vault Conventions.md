# Naming and Vault Conventions

## Folders

- `00 AI OS`: system design, agent prompts, architecture, roadmap, workflows
- `01 Research`: company, sector, and thematic research
- `02 Portfolio`: holdings, transactions, watchlists, client notes
- `03 Strategies`: strategy definitions and trading/investing rules
- `04 Backtests`: notebooks, results, and backtest summaries
- `05 Filings and Transcripts`: source documents and extracted text
- `06 Models`: valuation models and analytical models
- `07 Code`: code notes, repo maps, runbooks
- `08 Meetings`: meeting notes
- `09 Journal`: daily briefs and operating logs
- `Templates`: reusable note templates

## File Names

Use clear names that sort well:

- Company research: `Company Name - Research.md`
- Investment memo: `Company Name - Investment Memo - YYYY-MM-DD.md`
- Daily brief: `Daily Brief - YYYY-MM-DD.md`
- Source summary: `Company Name - Source - YYYY-MM-DD - Document Type.md`
- Decision log: `Decision - YYYY-MM-DD - Topic.md`

## Citation Style

Use this format:

`Source: document name, date, page/section if available, URL or local path`

For unsupported claims, write:

`Evidence status: needs source`
