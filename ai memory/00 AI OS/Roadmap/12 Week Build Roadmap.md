# 12 Week Build Roadmap

## Phase 1 - Foundation, Weeks 1-2

Goal: create the operating base.

Deliverables:

- Obsidian vault structure
- Agent roster
- Naming conventions
- Core templates
- SQLite schema draft
- First ingestion script plan
- Manual daily brief template

## Phase 2 - Memory and Retrieval, Weeks 3-4

Goal: make the vault searchable by agents.

Deliverables:

- Markdown indexer
- PDF ingestion pipeline
- Vector database setup
- Source metadata database
- Retrieval test workflow

## Phase 3 - Investment Data, Weeks 5-6

Goal: connect research to structured data.

Deliverables:

- Company master table
- Holdings and transactions tables
- Watchlist table
- Price import script
- Portfolio summary report

## Phase 4 - Specialist Agents, Weeks 7-8

Goal: activate role-based workflows.

Deliverables:

- Charlie Munger orchestrator prompt
- Jarvis runtime prompt
- Equity Research Agent prompt
- Valuation Agent prompt
- Risk Agent prompt
- Quant Agent prompt
- Coding Agent prompt
- Librarian Agent prompt

## Phase 5 - Automation, Weeks 9-10

Goal: reduce manual effort.

Deliverables:

- Daily brief generator
- Filing/transcript monitor
- Watchlist update job
- Portfolio risk job
- Run log notes

## Phase 6 - Interface and Polish, Weeks 11-12

Goal: make the OS pleasant to use.

Deliverables:

- Obsidian dashboards
- Command menu
- Research report format
- Portfolio dashboard
- Agent run history
- Backup and versioning process

## First Practical Milestone

Build one complete loop before building everything:

Research one company from source documents, save the memo in Obsidian, store key data in SQLite, retrieve it through vector search, and generate a portfolio/watchlist action note.
